# Litho Beta 2 Release Notes

## What's New

### Visual Inline Editing
Click any element directly on the page preview to make edits—no more typing complex descriptions. Changes accumulate in a panel where you can review everything before sending to the AI.

### Reset Preferences
New option in Settings to clear your profile, AI credentials, chat preferences, and app settings with one click.

### Page Count Information
The AI now has access to page count when browsing your documents, helping it understand document scope better.

## Improved

### Onboarding & Settings
- Redesigned AI provider selection with clear brand icons and cards
- Cleaner Settings layout for managing your providers

### Export Dialog
- Visual format cards make it easier to choose PDF, PNG, or JPG
- Better layout for a smoother experience

### Visual Design
- Improved contrast between cards and backgrounds for better readability
- Fixed scrollbar styling in the document viewer

## Fixed

- Chat conversations are now preserved if you abort a mid-turn response
- Free AI providers connect automatically as expected
- Fixed asset path issues when working with images and resources
- AI layout analysis is more accurate
- Build errors now show clearer feedback

## Performance

- Optimized how tool results are handled to reduce memory usage during long conversations
